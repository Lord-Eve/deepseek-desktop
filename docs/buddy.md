# CodeBuddy / WorkBuddy 原生接入

## 登录和运行

本程序直接通过 C# 访问对应区域的认证和模型服务。安装后不依赖官方 WorkBuddy / CodeBuddy 客户端、DeepSeek Harness、Node 或浏览器常驻。

若模型目录返回 `12403`，其已知含义是上游无法识别请求中的客户端版本标识（`check ua, get coding copilot version error`）。这是协议兼容问题，应更新本程序；安装官方客户端或反复更换账号不能修正旧版本发出的请求头。适配使用参考项目对应地区的产品标识与协议版本，并单独保留本程序版本。

1. 停止本地服务，在服务概览选择 CodeBuddy（国内版）或 WorkBuddy（国际版）。
2. 在账号管理填写名称，点击登录，在官方浏览器页面完成授权。国内个人账号使用微信或手机号；国际版可使用 Google 账号。
3. 返回本程序，看到授权保存成功后可关闭网页。取消登录或超时后请重新发起。
4. 按需主动刷新模型目录或查询积分，再启动本地服务。启动和目录查询不发送模型对话。
5. 客户端沿用程序显示的本地 API 地址和 Key，模型填写查询目录中返回的 ID。默认测试模型为 `deepseek-v4.1-flash`，实际访问权限以账号和上游响应为准。

两个区域的端点和授权分别管理。国内地址为 `copilot.tencent.com`，国际地址为 `www.workbuddy.ai`；不跨区域发送令牌。每个平台可以保留多个账号，目前每次仅启用一个。不读取其他软件、浏览器或插件的登录态。

授权连同账号、模型与连接设置使用 Windows DPAPI 加密保存。访问令牌到期前按需刷新，轮换令牌同步保存；本机保存失败时明确报错，避免把未保存的新授权当成已持久化。刷新令牌失效后需在浏览器重新登录。

## 接口与工具

本地服务仅监听 `127.0.0.1`，沿用本程序独立生成的 API Key。上游账号凭据不会交给调用本地 API 的客户端。

- `GET /v1/models`：返回当前区域的模型目录。
- `POST /v1/chat/completions`：文本流式与非流式、思考内容、函数工具声明及结果回传。
- `POST /v1/responses`：文本、思考摘要与函数工具兼容转换；客户端需回传完整 `input`，使用 `store: false`，不支持 `previous_response_id`。历史中其他供应商的加密思考无法解密，会丢弃密文、只保留可读摘要；`include` 可携带 `reasoning.encrypted_content`，但不会返回加密思考。
- MCP / Exa 等工具仍由原客户端执行；本程序只转发函数工具调用，不执行工具或读取工具凭据。

思考内容使用 `reasoning_content`，工具结果通过匹配的 `tool_call_id` 回传；客户端应保留完整对话历史。上游响应中断、工具调用不完整时返回错误，不把截断内容当成成功完成的可执行调用。模型支持的思考档位和输出上限取决于服务端配置。

Chat Completions 的正文与思考可以实时输出，工具调用完整收齐后才发送；Responses 流式接口先接收完整上游回复，再发送标准事件，因此首段输出较晚。当前只适配文本及函数工具，图片、音频、文件、内置搜索和结构化输出约束会明确拒绝；外部搜索可交给客户端的函数工具。模型目录里的多模态信息不表示本适配已支持相应内容。

本机每小时请求上限只限制本地请求数量，与腾讯积分余额或活动额度不同。余额查询展示上游返回的有效积分，不把未知余额当成零；不自动签到、领取奖励或制造活跃记录。国际版每日活跃奖励要求使用官方客户端，与反代服务的运行依赖无关。免费积分和模型限免可能调整，界面不写死活动期限。

请求串行处理，最多等待 8 个；排队最多 3 分钟，取得处理位置后重新计算最多 3 分钟的执行时间。排队超时会在本地结束，不向上游发送该次对话。积分资源包的无时区日期按北京时间判断，明确带时区的日期和秒／毫秒 Unix 时间戳按实际时刻判断；无法识别的到期时间会显示余额未确认。
