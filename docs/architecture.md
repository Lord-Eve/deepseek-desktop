# 架构与维护

## 数据流

```text
原生桌面窗口 ── DPAPI 加密设置
      │
      ├─ Windows Job Object 托管引擎进程
      └─ 私有临时 TOML 配置
                 │
        ds-free-api v0.5.1
           ├─ 127.0.0.1:22217/v1 → 客户端
           └─ DeepSeek 网页接口
```

桌面窗口不通过网页管理台工作。它用每次启动随机生成的内部管理凭据读取账号池与统计；面向客户端的 API Key 独立生成并保存。

持久设置位于当前用户的 DPAPI 文件。运行配置、原始后端日志和统计在私有临时目录中，停止服务后清理。窗口异常退出时，Windows Job Object 会结束后端；残留目录在下次启动时清理。

## 验证边界

- 核心回归验证字符串转义、配置校验、已知凭据脱敏和内部 JWT。
- Windows 原生回归验证 DPAPI 往返、目录 ACL、损坏配置拒绝覆盖和 Job 退出行为。
- 引擎契约回归运行真正的固定版本引擎，只有上游由本地模拟服务提供；不使用真实 DeepSeek 账号。
- Win11 窗口、托盘、多显示器 DPI 和真实账号可用性仍需人工验收。

## 发布维护

1. 更新 `.csproj` 版本、`CHANGELOG.md` 与 `docs/releases/v版本.md`。
2. 推送 main，等待 Windows build and checks 通过。
3. 创建并推送相同版本的 tag，例如 `v0.1.0`。
4. Release workflow 重新执行检查与自包含构建，上传 ZIP、校验文件并创建预发布。

试用阶段保持 prerelease 标记。发布资产包含桌面端源码、上游对应源码与许可证。不要重新使用已有 tag 覆盖资产；修复后递增版本。
