## 更新与登录

1. 在程序内检查 GitHub 更新，由你自行下载并替换常用软件目录中的完整程序包。同一 Windows 用户沿用原有加密账号、API Key、端口和连接设置。
2. 停止服务，选择“Grok OAuth（CLI 通道）”，在账号管理填写名称并点击“登录 / 重新登录 Grok”。
3. 在 xAI 官方网页授权。自动回调成功时直接返回程序；如果网页显示“Enter this code to finish signing in”，复制授权码，返回本程序粘贴到授权码框，点击“完成登录”。无需另开 Grok CLI。
4. 每次登录最多等待 5 分钟，可取消。旧版发起或已取消、超时的授权不能在新版继续，请重新发起登录并使用新页面的代码。不要把授权码发到聊天或日志中。
5. 保存授权后启动服务，先发送测试消息，再在原客户端验证已配置的 Exa MCP。建议先用 `grok-build`，其他模型预设的实际权限以官方账号为准。

## 功能与边界

- 独立 OAuth/PKCE 登录，凭据使用 Windows DPAPI 保存，支持刷新与轮换；不读取 Cherry Studio / Grok CLI 登录文件。
- 支持文本 Chat Completions、原生 Responses 和结构化函数工具调用；MCP 工具仍由原客户端执行。
- Chat Completions 工具上下文与加密思考只缓存于内存，最多 128 项、16 MB、30 分钟，绑定账号、模型和历史；重启或缓存失效后需新建会话。
- Responses 需提供完整历史，使用 `store=false`，不支持 `previous_response_id`；Chat Completions 暂仅支持文本。
- 每次启用一个 Grok 账号，串行处理请求。启动不发送模型对话或查询额度；预设目录不保证账号具备全部模型权限。
- 手动授权码仅提交给当前登录会话，自动回调与手动提交只兑换一次；取消或超时后失效，授权码不写入设置或日志。
