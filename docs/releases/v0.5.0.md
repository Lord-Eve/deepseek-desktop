新增 CodeBuddy（国内版）和 WorkBuddy（国际版）原生接入。授权后日常只需运行 DeepSeek Desktop，无需安装或常驻官方客户端、DeepSeek Harness、Node 或浏览器。

## 新增功能

- 停止服务后，可在服务概览选择 CodeBuddy 国内版或 WorkBuddy 国际版。两区分别保存账号、授权和默认测试模型，每个平台每次启用一个账号。
- 账号管理支持浏览器登录、取消和超时；国内个人版使用微信或手机号，国际版可使用 Google 账号。官方网页授权完成后返回程序，看到保存成功即可关闭网页。保留 `auth.workbuddy.ai` 作为国际版授权页的合法域名。
- 凭据通过 Windows DPAPI 加密保存，访问令牌到期前按需刷新，轮换刷新令牌同步保存；本机保存失败会明确报错。
- 主动读取当前账号的模型目录和有效积分余额。启动服务只刷新授权和目录；只有客户端请求或“发送测试消息”才会调用模型。不自动签到或领取奖励。
- 提供 `/v1/models`、Chat Completions 文本流式／非流式、思考内容、原生函数工具调用及结果回传，以及无存储 Responses 文本／函数工具兼容。

## 协议与边界

Chat 正文和思考可实时输出，工具调用完整接收并验证后才发送给客户端；外部 MCP / Exa 等工具由原客户端执行。Responses 流式先接收完整上游回复再发送标准事件，首段输出较晚；使用 `store: false` 并回传完整 `input`，不接受 `previous_response_id` 或其他供应商的加密思考。

本版已处理空中间结束标记、重复工具标识、目录缺失或不一致的默认思考档位，以及 Responses 同轮正文、思考和多个工具调用的合并。排队与执行分别最多 3 分钟；排队超时不会发送该次上游请求。登录过程中单次轮询超时可继续等待，主动取消仍立即终止。

积分按上游有效资源包的本周期余额合计，过滤到期包；无时区日期使用北京时间，显式时区及 Unix 秒／毫秒按实际时刻解析。无法确认余额时明确显示未知，不显示为零。免费积分、活动期限及模型权限仍由账号和上游服务决定。

当前适配文本及函数工具；图片、音频、文件、内置搜索和结构化输出约束会明确拒绝。可以使用客户端配置的函数工具完成外部搜索。完整步骤见 [接入说明](../buddy.md)。

## 更新与验证

0.4.0 及以上版本可在“连接设置 → 数据与版本”检查更新，点击“下载并重启更新”。保留原有账号、本地 API Key、端口和连接设置；客户端模型请使用当前区域 `/v1/models` 返回的 ID，默认测试模型为 `deepseek-v4.1-flash`。

相关验证使用虚构凭据、模拟 HTTP 上游及本地回环接口，不消耗真实额度。真实网页登录、验证码、模型权限、实际积分扣减和完整客户端人工验收仍须用户在本机确认。发布包由 GitHub CI 完成全部发布检查和构建，通过现有更新入口交付。
