新增智谱清言支持的本机试用版，继续保留 DeepSeek 功能及原有应用名称、图标和加密数据目录。

1. 在“服务概览”选择“智谱清言”。切换平台前先停止服务。
2. 在自己的浏览器登录 chatglm.cn 并确认可正常对话，在开发者工具 Application → Cookies 或 Local Storage 中取得 `chatglm_refresh_token`。
3. 在“账号管理”添加名称和 refresh token，保存后启动服务。启动会校验登录态，不发送对话。
4. 点击“发送测试消息”。客户端沿用原有地址及 Key，模型改为 `qingyan-default`。

清言当前支持文本 Chat Completions、流式/非流式回复及通过文本拼接传递多轮历史。每次请求创建独立网页会话并尽力删除；删除失败时，网页可能残留会话。模型别名代表网页默认模式，不保证特定 GLM 版本。

清言暂不支持工具调用、图片、音频、文件、结构化输出、Responses、Anthropic 兼容路由或专门的深度思考切换。不能把 DeepSeek 之前的 AstrBot 验收结果当作清言已经验收。

设置保存在原有 `%LOCALAPPDATA%\DeepSeekDesktop`，升级时无需迁移、重新录入 DeepSeek 账号或生成新 Key。两平台账号分开显示，清言凭据使用 Windows DPAPI 加密，轮换时自动保存新值，不写入 Rust 引擎临时配置。

本机检查使用模拟上游，不访问真实账号：32 项核心检查、29 项清言网关/协议检查、19 项隔离 WPF 检查及 8 项 Windows 原生检查。用户随后已在自己的环境确认清言 API 正常调用。完整流式/多轮场景、各客户端兼容和跨时段刷新仍需单独验收，不能据此承诺网页协议长期可用。
