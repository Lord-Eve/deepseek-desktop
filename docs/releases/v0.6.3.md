## 本次变更

- 上游返回 `11158` 时，提示“当前账号套餐不能使用该模型”，状态码改为 403，不再误报为“请求参数或当前接入方式被上游拒绝”。WorkBuddy 国际版免费账号不能调用 GPT、Gemini、Grok 等，可用 DeepSeek、GLM、Kimi、混元等。
- 模型目录不按账号套餐过滤。现在读取上游的套餐层级，在 `/v1/models` 的模型名后标注“Pro Only”等官方文案，并新增 `tier` 字段；“获取账号模型列表”也会列出这些模型。国内版的“订阅优先”只影响排队，仍可调用。
- 检查更新和下载更新使用“连接设置”中的上游代理地址。Clash 开启 TUN 模式时程序内下载可能停在 0 字节，填写 Clash 的 HTTP 端口（例如 `http://127.0.0.1:7897`）即可。该地址同时用于模型请求。

## 更新后使用

在“连接设置 → 数据与版本”点击“检查更新”，再点击“下载并重启更新”。如果下载卡住，先停止服务，在“上游代理地址”填写代理并保存，再重新更新。账号授权、端口、API Key 和记住的服务状态保留。

## 验证边界

自动检查使用虚构凭据和模拟上游。`11158` 的含义依据用户实测和多个第三方项目的记录；真实 Pro 账号上的层级标注、在程序内填写代理后完整走一次更新，须更新后确认。发布包由 GitHub CI 执行完整发布检查并构建交付。
