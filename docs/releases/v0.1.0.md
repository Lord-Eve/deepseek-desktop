首个私有项目基线，提供 Win11 x64 原生桌面客户端和本地 OpenAI 兼容 API。

- 账号添加、编辑、启停与 Windows DPAPI 加密保存。
- 本机服务启停、端口占用检查、系统托盘和进程生命周期托管。
- API 地址与 Key 复制、模型列表检查、主动对话测试、账号池和请求统计。
- 固定 ds-free-api v0.5.1，引擎启动前校验 SHA-256；发布包附完整对应源码和许可证。
- 自动执行核心回归、Windows DPAPI/ACL/Job 原生检查和真实引擎的本地模拟上游契约检查，然后打包发布。

下载 ZIP 后完整解压，运行 `DeepSeekDesktop.exe`，保留旁边的 `engine/` 文件夹。自包含包无需额外安装 .NET、Node 或 Python。

本版本仍为试用：尚未验证真实 DeepSeek 账号、跨时段使用、实际 Win11 桌面操作及 AstrBot、Eve pet、tibo watch、Cherry Studio 的真实接入。登录需要密码和真实 device_id，暂不处理自动浏览器登录与验证码。固定引擎在启动账号时会发送健康检查消息。

默认 Base URL：`http://127.0.0.1:22217/v1`；模型 `deepseek-default` 代表网页默认模式，不是具体官方模型版本。账号受限和上游协议变化仍可能影响使用。
