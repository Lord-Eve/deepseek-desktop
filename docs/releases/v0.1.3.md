本次增加更新入口，协议引擎仍固定为 ds-free-api v0.5.1。

- “连接设置 → 数据与版本”中可点击“检查更新”或“前往下载页”。
- 启动时后台检查新版，发现更新后显示侧栏入口；检查不会启动、停止或打断本地 API 服务，也不会弹出系统通知。
- 仓库保持私有。自动检查需要本机安装 GitHub CLI，已登录且有本仓库访问权限；缺少该条件或网络出错时，可直接通过浏览器登录 GitHub 后查看下载页。
- 发布版使用预览标记，检查会包含已有 Windows ZIP 的预览版本，并按数字版本号选择新版；草稿及缺少 Windows 包的版本不会提示下载。

本版提供检查和下载页入口，升级步骤为：退出旧程序，下载并解压完整新包，再启动新版。同一 Windows 用户下沿用 `%LOCALAPPDATA%\DeepSeekDesktop\settings.dpapi` 中的账号、API Key 和连接设置。

所有开发和构建仅在 Git 工作区进行，不修改原安装目录。自动检查不读取 DeepSeek 账号，真实账号对话和跨时段稳定性未在本版重新验收。

本机已通过 27 项核心检查和 14 项界面检查，并使用新增检查器实际读取了私有仓库的当前发布版本。发布工作流会执行现有检查与打包。
