新增“记住服务状态”：点过“启动服务”后，重启电脑或退出后再打开程序，服务会自动恢复。

## 本次变更

- 点击“启动服务”成功后记住状态，下次打开程序自动启动当前平台的服务；点击“停止服务”后下次不自动启动。退出程序和关机不改变状态。DeepSeek、清言、Grok、CodeBuddy、WorkBuddy 行为一致。
- 新增启动参数 `--start-service`：本次启动时拉起服务，不改变记住的状态。程序已在运行时不弹窗，由运行中的实例启动服务。
- 新增启动参数 `--tray`：不显示窗口，只显示托盘图标。
- 自动启动只尝试一次。失败时不弹窗，错误显示在服务概览和运行日志中，记住的状态不变。

## 更新后使用

在“连接设置 → 数据与版本”点击“检查更新”，再点击“下载并重启更新”。账号授权、端口和 API Key 保留。更新时服务正在运行的，会自动记为已启动；未运行的，点一次“启动服务”后开始记住。

开机脚本可使用：

```text
DeepSeekDesktop.exe --start-service --tray
```

程序本身不注册开机自启。开机时网络可能尚未就绪，脚本可以等网络可用后再启动，或在失败后再执行一次 `--start-service`。启动是否成功以 `http://127.0.0.1:端口/v1/models` 是否响应为准。

注意：DeepSeek 启动时会登录账号并由引擎发送健康检查消息，自动启动同样如此。

## 验证边界

自动检查和隔离实测均使用虚构账号与本地环境，未发送真实模型消息。真实关机或注销后的恢复、真实账号的自动启动须更新后确认。发布包由 GitHub CI 执行完整发布检查并构建交付。
