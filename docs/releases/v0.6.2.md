程序内更新增加下载进度条；下载卡住时会自动停止，不再长时间停在“正在下载”。

## 本次变更

- 下载更新包时显示进度条，以及已下载和总大小（MB）、百分比。校验和解压阶段无法计量，显示为滚动进度。
- 连续 60 秒没有收到数据时自动停止下载，并提示检查网络或代理后重试。稳定但较慢的下载不受影响，总时限放宽到 60 分钟。

## 更新后使用

在“连接设置 → 数据与版本”点击“检查更新”，再点击“下载并重启更新”。账号授权、端口、API Key 和记住的服务状态保留。进度条从更新到本版之后的下一次更新开始显示；本次从旧版更新时仍沿用旧的下载界面。

## 验证边界

自动检查覆盖进度计算、卡住判定和界面显示，使用临时目录与虚构数据。真实下载过程中的进度刷新和卡住后自动停止须在下次更新时确认。发布包由 GitHub CI 执行完整发布检查并构建交付。
