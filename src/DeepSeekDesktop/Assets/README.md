# 应用图标

`deepseek-whale-girl.png` 为内置 imagegen 工具生成的透明 PNG；`deepseek-whale-girl.ico` 从该图转换，包含 16、20、24、32、40、48、64、128、256 像素尺寸，供 EXE、WPF 窗口和系统托盘使用。

该插画是本项目的鲸鱼娘头像，并非 DeepSeek 官方角色立绘。原始透明像素保留在 PNG 中，ICO 仅进行尺寸转换和格式编码。

生成提示词：

```text
Use case: stylized-concept. Asset type: a single finished square Windows desktop application icon for an unofficial DeepSeek desktop client. Primary request: DeepSeek 鲸鱼娘, a cute chibi anime whale-girl head and shoulders portrait with blue hair and a recognizable blue whale themed hood (white belly panel, tiny whale fin at each side, a short upward whale tail tuft on the hood), large friendly blue eyes and a small cheerful smile. Style: clean polished anime mascot icon, crisp bold navy outlines, simple broad shapes and flat cel shading, very little fine detail. Color palette: DeepSeek blue, cobalt blue, navy, white, pale skin. Composition: centered frontal headshot, character fills most of the square, entire head and fins fully visible, generous enough outer transparent margin for an app icon, circular silhouette. Actual transparent background, no scene and no square tile background. It must read well at 16, 24, 32, 48 and 256 pixels. No text, no letters, no watermark, no border, no extra props, no extra characters. This is a human anime mascot with a whale hood, not just a whale animal. Final output is one isolated icon only.
```
